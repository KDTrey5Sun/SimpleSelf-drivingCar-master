核心RQ（最终版本 - 二维联合优化）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
主RQ（精炼版）：
  How do replay buffer capacity and mini-batch size jointly affect 
  sample efficiency, training stability, and computational throughput 
  in Deep Q-Learning for continuous control with dense reward shaping?

理论定位：
  将经验回放视为"数据低通滤波器"（Data Low-Pass Filter）
  - Buffer容量 = 滤波器记忆长度（时间常数）
  - Batch size = 梯度估计采样密度
  - 联合作用决定策略更新的"信噪比"

研究逻辑（双核心+一扩展）：
  核心1：样本效率分析 → Buffer/Batch各自主效应 + 交互效应验证
  核心2：训练稳定性诊断 → 高方差根因识别 + 缓解策略验证
  扩展：机制解释（可选）→ 数据重用率、Q值漂移的理论分析

SRQ1：联合优化的样本效率分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Question: 
  How do buffer capacity and batch size jointly determine sample efficiency?
  Is there an interaction effect beyond additive contributions?

Metrics（三层粒度）：
  【粗粒度 - 全局指标】
  • samples_at_first_success：首次成功所需的环境交互总步数
  • episodes_to_convergence：达到收敛（success_rate > 0.90）所需episode数
  
  【中粒度 - 里程碑追踪】
  • samples_at_milestones：达到25%, 50%, 75%, 90%性能时的累积样本数
  • 计算方法：在每个episode结束时，用最近100ep的success_rate判断
  
  【细粒度 - 学习曲线斜率】
  • learning_rate_early：前20%训练时间的reward增长斜率
  • learning_rate_late：后20%训练时间的斜率（检测是否plateau）

Hypothesis H1（二维交互假设）：
  H1a：Buffer容量主效应（单轴U型）
    - 1K: 高重用（320×）→ 数据多样性崩溃 → 样本效率低
    - 10K-50K: 平衡点（10-30×重用）→ 最高效
    - 100K: 陈旧数据主导（3×重用）→ Q值漂移严重 → 效率下降
  
  H1b：Batch size主效应（单轴倒U型）
    - 4: 梯度估计噪声大 → 需要更多更新步 → 总样本多
    - 64-128: 梯度稳定且更新频率合理 → 最高效
    - 256: 更新频率过低（同样样本下更新次数减半）→ 效率下降
  
  H1c：交互效应（关键发现点）
    - 小Buffer + 大Batch = 灾难（样本重用率爆炸 + 更新稀疏）
    - 大Buffer + 小Batch = 次优（陈旧数据 + 高方差梯度相互放大）
    - 最优组合：中等Buffer + 中等Batch（例如 10K + 64）
    
  验证方法：
    ✓ 2D热力图：Buffer(行) × Batch(列) → steps_to_success
    ✓ 交互效应检验：two-way ANOVA，检验F(Buffer×Batch) 是否显著
    ✓ 对比：最优组合 vs 两个单轴最优点的组合

SRQ2：高方差问题的机制诊断与缓解
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Question: 
  What causes the extreme run-to-run variability (CV > 50%) in current experiments?
  Which hyperparameter configuration minimizes variance while maintaining efficiency?

背景问题（必须解决）：
  ⚠️ 当前实验发现：buffer=100K时，avg_loss的error bar跨越400+单位
  ⚠️ 同配置下success_rate范围0.05-0.67（13倍差异）
  ⚠️ 根本原因未知，怀疑多稳态收敛（multi-modal policy space）

Metrics（分层诊断）：
  【层级1：宏观变异性】
  1. Success Rate变异系数（主指标）：
     CoV_success = std(success_rates across seeds) / mean(success_rates)
     目标：从当前 >0.50 降低至 <0.25
  
  2. 最终性能标准差：
     σ_score = std(final_avg_score across seeds)
     相对标准差：RSD = σ_score / mean(score)
  
  【层级2：过程稳定性】
  3. 收敛轨迹一致性：
     - 不同seed的学习曲线之间的动态时间规整（DTW）距离
     - 低DTW = 轨迹形状相似，只是时间尺度不同
     - 高DTW = 根本性的策略差异（例如：激进 vs 保守驾驶）
  
  4. TD-Loss方差演化：
     - batch内方差：var(TD_errors within single batch)
     - 跨batch方差：std(avg_loss over consecutive 100 batches)
     - 高方差期持续时间 = 首次方差低于阈值前的episode数
  
  【层级3：深层机制】
  5. Q值健康度监控：
     - q_value_mean：平均Q值（检测爆炸/消失）
     - q_value_max：最大Q值（极端值检测）
     - q_value_std：Q值标准差（分布宽度）
     正常范围：mean在[-100, 5000]，max不超过10000
  
  6. Epsilon衰减与探索充分性：
     - samples_at_epsilon_min：epsilon达到0.05时的累积样本数
     - 当前问题：epsilon与learning_step耦合 → batch_size影响探索时长
     - 期望：解耦后，所有配置在相同env_step达到epsilon_min

Hypothesis H2（多来源方差假设）：
  H2a：奖励尺度不匹配导致的"彩票学习"
    问题：terminal奖励(±3000) >> step奖励(0.2-12) [150-15000倍]
    后果：早期遇到大奖励的seed会形成完全不同的Q值尺度
    证据：大buffer中Q值方差异常大（陈旧数据保留早期错误估计）
    
  H2b：Epsilon衰减耦合问题
    问题：epsilon按learning_step衰减 → batch越大，同样env_step下epsilon越高
    后果：
      - batch=4：10000 env_steps → 约2500次更新 → epsilon=0.75
      - batch=256：10000 env_steps → 约39次更新 → epsilon=0.996
    导致：大batch配置长期处于随机探索，收敛极不稳定
    
  H2c：多稳态策略空间
    假设：存在多个局部最优策略：
      - 激进策略：高速过弯，高奖励但高风险（容易失败）
      - 保守策略：慢速稳定，中等奖励但稳定收敛
    不同seed的随机初始化 → 收敛到不同吸引子
    大buffer加剧问题（保留早期探索的不同策略痕迹）
  
  H2d：目标网络更新频率不足
    当前：hard replace每5000步（或soft update τ=0.005）
    问题：策略快速演化时，Q_target滞后 → TD-target震荡
    大buffer + 大batch时最严重（单次更新信息量大）

验证方法与缓解策略（实验设计）：
  ✓ 消融实验1：奖励尺度归一化
    对比：原始奖励 vs scaled奖励（/100） vs clipped奖励（[-10,10]）
    预期：缩小尺度差异后，CV下降20-40%
  
  ✓ 消融实验2：Epsilon衰减解耦
    修改：epsilon按env_step衰减（而非learning_step）
    预期：消除batch_size对探索的影响，CV下降10-20%
  
  ✓ 消融实验3：软目标网络更新
    对比：hard replace(5000) vs soft update(τ=0.001/0.005/0.01)
    预期：τ=0.005时CV最低（平滑更新减少震荡）
  
  ✓ 失败模式分类
    统计：collision / timeout / stagnation / finish 的分布
    分析：不同配置的失败原因是否系统性不同？
    （小buffer → 更多collision，大buffer → 更多timeout）

  • 内存不是瓶颈（即使100K buffer也仅2MB）

SRQ3：因果机制链条的实证验证（可选深度分析）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Question: 
  What are the causal pathways from Buffer-Batch configuration 
  to final performance? Can we validate theoretical predictions?

理论框架：数据低通滤波器模型（Data Low-Pass Filter）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
类比：Replay Buffer = 电路中的电容器
  • Buffer容量 ≈ 电容值C（存储电荷能力）
  • Batch size ≈ 放电速率（单次提取电荷量）
  • 数据流入 ≈ 充电电流（env interaction）
  • 学习更新 ≈ 放电过程（采样消费）

滤波特性：
  • 截止频率：f_c ∝ batch_size / buffer_capacity
    - 高频（策略快速变化）→ 被滤除（大buffer平滑）
    - 低频（长期趋势）→ 保留
  
  • 时间常数：τ = buffer_capacity / (batch_size × learning_freq)
    - 小τ（小buffer或大batch）：快速响应策略变化，但噪声大
    - 大τ（大buffer或小batch）：平滑稳定，但响应滞后

理论预测 → 实验验证链条：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【因果链1：样本相关性 → 梯度偏差 → 收敛速度】
  理论：
    小buffer + 大batch → 采样到时间接近的样本
    → batch内状态高度相关（违背i.i.d.假设）
    → 梯度估计方差↓，但偏差↑
    → 可能陷入局部最优或收敛到错误策略
  
  验证指标：
    • Batch内样本时间跨度（temporal_span）
    • 状态相似度：pairwise cosine similarity in batch
    • 梯度估计质量：对比单样本梯度 vs batch平均梯度
  
  实验：
    对比(1K, 256) vs (100K, 4)，控制reuse_rate相同
    → 若性能差异显著，证明相关性独立于重用率起作用

【因果链2：Q值漂移 → TD-target不稳定 → 训练振荡】
  理论：
    大buffer保留陈旧样本 → 这些样本采集时策略版本过时
    → 计算TD-target时，r + γ max Q_target(s', a') 中的Q_target
       基于旧策略，与当前策略Q_eval不匹配
    → Loss震荡，策略不稳定
  
  验证指标：
    • Q值漂移：Δq = |Q_eval(s,a) - Q_target(s,a)| for old samples
    • Target更新滞后：|θ_eval - θ_target| (参数欧式距离)
    • TD-error分布：画histogram，看是否双峰（新旧样本两组）
  
  实验：
    在100K buffer中，分层采样：
    - 新鲜样本（age < 1000 steps）
    - 陈旧样本（age > 50000 steps）
    计算两组的平均TD-error和Q漂移
    → 预期：陈旧组的drift显著更大

【因果链3：重用率 → 过拟合风险 → 泛化能力】
  理论：
    极高重用率（>100×）→ 网络反复见到相同样本
    → 记忆特定轨迹而非学习通用策略
    → 在训练轨道上过拟合，泛化差
  
  验证指标：
    • 训练损失 vs 验证损失（需要hold-out验证集）
    • 网络记忆度：检查网络是否对特定(s,a)产生异常高Q值
  
  实验（简化版，无需多轨道）：
    在同一轨道上，训练后：
    1. 随机初始化位置测试（与训练起点不同）
    2. 添加小噪声（±5px位置扰动）
    比较：(1K, 256) vs (50K, 64) 的性能下降幅度
    → 若1K配置下降更多，证明过拟合

【因果链4：Batch size → 更新频率 → 样本利用效率】
  理论：
    固定total_samples：
    - 小batch → 更多更新步（10000 steps × 4 = 40K samples）
    - 大batch → 更少更新步（625 steps × 256 = 160K samples）
    
    但样本总数相同时：
    - 小batch：高频小幅更新，梯度噪声大但探索充分
    - 大batch：低频大幅更新，梯度准确但可能错过细节
  
  验证指标：
    • Learning steps to convergence（更新次数）
    • Samples to convergence（样本数）
    • 效率比：samples_per_step = total_samples / learning_steps
  
  实验：
    控制total_samples相同（如100K），调整batch：
    - (50K, 4)：25000次更新
    - (50K, 256)：~390次更新
    → 比较哪个先收敛？哪个最终性能更好？

综合假设：三因素交互模型
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  最优配置满足三个条件：
  1. 重用率适中（10-50×）：避免过拟合但保证充分学习
  2. 样本相关性低（temporal_span > 10 episodes）：保证梯度无偏
  3. Q漂移可控（平均age < 5000 steps）：保持TD-target准确性
  
  数学表达（定性）：
    performance ∝ f(reuse_rate) × g(correlation) × h(drift)
    
    其中：
    - f: 倒U型（峰值在20-30×）
    - g: 递减（相关性↑ → 性能↓）
    - h: 递减（漂移↑ → 性能↓）
  
  验证：
    多元回归分析：
    y = steps_to_target
    x1 = reuse_rate
    x2 = avg_temporal_span
    x3 = avg_q_drift
    
    拟合：y ~ β0 + β1·x1 + β2·x1² + β3·x2 + β4·x3 + ε
    检验：
    - β2 < 0（U型关系）
    - β3 < 0, β4 > 0（负面影响）
    - R² > 0.7（模型解释力强）

Chapter 5: Discussion
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5.1 Key Findings Summary
  • 发现1：存在Buffer-Batch交互效应（非简单叠加）
  • 发现2：奖励尺度不匹配是高方差主因（缓解59%）
  • 发现3：最优重用率区间15-40×（过高/过低都差）
  • 发现4：场景化推荐优于"一刀切"配置

5.2 Theoretical Implications
  • 数据低通滤波器模型的实证支持
  • 样本相关性-偏差-效率的三角关系
  • 多稳态策略空间的普遍性（需进一步验证）

5.3 Practical Guidelines
  **Decision Tree for Practitioners**:
  ```
  IF memory < 10MB THEN
    USE (5K, 64) + reward_scaling
  ELIF time_critical THEN
    USE (10K, 128) + GPU
  ELSE
    USE (50K, 64) + soft_target
  ```

5.4 Limitations & Future Work
  • 单任务局限：泛化到其他环境？
  • 密集奖励依赖：稀疏奖励下结论是否成立？
  • 优先级回放：PER是否改变最优配置？
  • 自适应Buffer：动态调整容量的可能性？
